## 二、全書語法核心遞進線 (Grammar Progression Roadmap)

本冊語法設計由淺入深，嚴格對標小六銜接國中的時態與句型核心：
```mermaid
graph TD
  U1["Unit 1: -ed vs -ing 形容詞<br>(修飾人感知 vs 修飾事物特質)"] --> U2["Unit 2: 動名詞 Gerunds (V-ing)<br>(like / enjoy / finish 後接動名詞)"]
  U2 --> U3["Unit 3: 情態助動詞 Can / Could<br>(現在能力 vs 過去能力對比)"]
  U3 --> U4["Unit 4: 條件句 If / When<br>(Present Real Conditional: 現簡 + 現簡)"]
  U4 --> U5["Unit 5: 過去進行式 Past Continuous<br>(was / were + V-ing 明確時間點動作)"]
  U5 --> U6["Unit 6: 過去進行式 + 過去簡單式<br>(長動作 was V-ing + when + 短插曲 V-ed)"]
  U6 --> U7["Unit 7: 未來事實 Future Facts (will / won't)<br>(客觀科學規律與預測)"]
  U7 --> U8["Unit 8: 未來計畫 Future Plans (be going to)<br>(意圖、安排與即將發生的事件)"]
```

## 三、AI 出題與教研規範指引 (AI Instruction Guidelines)

1. **嚴守當前單元邊界**：
   - 當學童在練習某一單元時，AI 出題用詞嚴格鎖定該單元前進範圍內的詞彙與文法。
   - **禁止超前混淆**：例如在 Unit 1 測驗中，嚴禁出現 Unit 5 的過去進行式（was/were doing）作為干擾項。
2. **段考與全民英檢考點滲透**：
   - 小六段考必考陷阱：
     - `-ed` 形容詞（修飾感到...的人）與 `-ing` 形容詞（修飾令人...的事物）的混淆。
     - 動名詞作受詞（enjoy watching 而非 enjoy to watch）。
     - When / While 連接詞後的時態一致性。
     - Will 與 Be going to 在語氣（即時決定 vs 事先規劃）上的細微差異。
