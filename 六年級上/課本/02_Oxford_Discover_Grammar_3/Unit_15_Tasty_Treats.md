### 【p.77 學習文法 Learn Grammar】

#### 核心文法規則框：Learn Grammar — Count and Noncount Nouns
*(漫畫角色：右側有藍色火焰小精靈 Harry 探出頭來眨眼。)*

> **Remember!**
> - **Count nouns are nouns which have a singular and a plural form.**
>   - *a tomato* ➔ *one tomato* ➔ *two/three/etc. tomatoes*
> - **Noncount nouns are nouns which only have a singular form.**
>   - *olive oil* ➔ **NOT** *an olive oil* / *one olive oil* / *olive oils*
> - **Sometimes a noun has a count sense and a noncount sense:**
>   - *four mini pizzas* (整塊披薩) ➔ *a piece of pizza* (一片切塊披薩)
>   - *two tomatoes* (整顆番茄) ➔ *two slices of tomato* (兩片番茄薄切)
> - **Use *how many ...?* with plural count nouns.**
>   - **How many** tomatoes do we have?
> - **Use *how much ...?* with noncount nouns.**
>   - **How much** olive oil do we need?

#### D. Read and learn.
*(核心規則框：Measure Phrases 計量詞對照表)*

> **Measure phrases help you to count things you usually can't count, such as juice or rice. They can also be used to count larger numbers of things you can count, such as apples and pencils.**

| 容器/形狀計量詞 | 常見搭配名詞範例 |
| :--- | :--- |
| **a bottle of** | water / olive oil / lemonade |
| **a packet of** | sugar / biscuits / crisps |
| **a bag of** | flour / rice / apples |
| **a carton of** | milk / juice / eggs |
| **a cup of** | coffee / tea *(食譜中: sugar / butter)* |
| **a bar of** | chocolate / soap |
| **a glass of** | water / milk / cola / juice |
| **a can of** | cola / tomatoes / soup |
| **a bowl of** | soup / rice / apples |
| **a box of** | cereal / chocolates / cookies |
| **a jar of** | honey / jam |
| **a pound / kilo of** | meat / cheese / potatoes |
| **a slice of** | tomato / bread / cheese |
| **a piece of** | cake / pizza / cheese |

### 【p.79 篇章對話與食譜寫作 Let's Write!】

#### F. Choose the correct words to complete the conversation.
*(插圖說明：右上角展示兩名學童大頭照，女孩 Karima 穿著牛仔外套長髮披肩，男孩 Tarik 留著平頭微笑。)*

- **Karima**: Let's make a cake for Grandma and Grandpa.
- **Tarik**: That's a good idea. What do we need?
- **Karima**: We need a **¹ [a. carton]** of eggs, and some butter.
- **Tarik**: OK. Do we need a **² [a. bag]** of flour?
- **Karima**: No. There's a lot of flour in the cupboard. But we need a **³ [b. bar]** of chocolate for the cake.
- **Tarik**: OK. Do we need a **⁴ [c. carton]** of milk?
- **Karima**: No. We've got some milk in the fridge. But we need some coffee.
- **Tarik**: Why? Are we making a coffee cake?
- **Karima**: No. But Grandma always drinks a **⁵ [c. cup]** of coffee when she eats a **⁶ [a. piece]** of cake!

**題目選項與正解：**
1. **a carton** / b jar / c bottle *(正解：a)*
2. **a bag** / b bar / c jar *(正解：a)*
3. a jar / **b bar** / c can *(正解：b)*
4. a pound / b box / **c carton** *(正解：c)*
5. a bag / b bottle / **c cup** *(正解：c)*
6. **a piece** / b bowl / c glass *(正解：a)*
