# 國小六年級上學期英語學習系統 (English Review 6)

> 專為國小六年級設計的英語全方位學習系統。涵蓋 Oxford Discover 3、Oxford Discover Grammar 3、Reading with Writing 6、Write Right 3、Read and Discover 6 等教材與歷史小考真題。

## 🌟 核心特色

1. **閱聽單字卡 (Word Cards)**：支援美式真人發音、詞性音標、例句朗讀與熟練度標記。
2. **神探點詞抓錯 (Mistake Buster)**：精選歷史考券真實失分錯題，免鍵盤直覺點選單字抓錯並訂正。
3. **紙筆 / 語音雙軌測驗 (Dual Quiz Arena)**：
   - 包含五大題型專項突破：`[全部題型]`、`[單字盲聽]`、`[課文填空]`、`[文法選擇]`、`[句子改寫]`。
   - 單字盲聽模式：電腦自動發音（1.0x / 0.8x 慢速精聽），小朋友紙筆聽寫後翻牌核對音標與音節拆解。
   - 三段式硬核教研詳解：`🎯 核心考點`、`🔑 破題公式`、`⚠️ 考場致命盲點`。
4. **期中衝刺 A4 試卷列印中心**：
   - 歷史考券 1:1 復原重測卷。
   - 考券紅黑批改對照卷（灰黑手寫原答 vs 鮮紅老師批改與防坑解析）。
   - AI 變式狙擊卷（相同文法語境，人名情境隨機抽換）。
5. **終身錯題本 (Error Notebook)**：LocalStorage 持久化記錄所有錯題，支援自訂篩選與重測。

## 🚀 快速啟動

本專案為 **Zero-Build Vanilla SPA**，無需安裝 Node.js 或打包建置工具：
- 直接以瀏覽器開啟 `index.html` 即可完整使用。
- 支援靜態網頁伺服器（如 Python `http.server` 或 GitHub Pages）。
